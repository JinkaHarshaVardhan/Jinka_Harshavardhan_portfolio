## Multilingual Sentiment Analysis {#sentiment}

### Problem

Product teams need quick insight from multilingual customer reviews without manual labeling overhead.

### Solution

A Streamlit web app ingests review text, runs NLP sentiment models, and visualizes polarity distributions across languages.

### Tech Stack

- Python, Streamlit, NLP
- Transformers / classical ML
- Pandas

### Architecture

```
User Input → Preprocessing → Sentiment Model → Aggregated Dashboard
```

### Results

Interactive exploration of review sentiment at scale; demonstrates end-to-end ML product skills from model to UI.
